⑤ Mode B 无可调参数

旧版的 mincutoff / beta / gravityAvgMs 三个滑杆已删除：链路改成纯投影后， 任何滤波都会重新引入滞后，而加速度计污染根本不在滤波能处理的频段里（快速翻转时手部线加速度达 2–3 g）。 因此 Mode B 与 Mode A 现在是同一条架构，没有需要调的东西，也不会被调试页悄悄改掉主控手感。

⑥ 本机能力自检 — 按键震动

快捷键面板按下时会调 navigator.vibrate() 做确认。这里直接问浏览器要答案： API 在不在、每次调用是"被拒"还是"已接受"——看返回值就能分清是谁的问题： 返回 false = 调用被拒（页面不可见、或没有用户手势时会被拒）； 返回 true 但手上没感觉 = 调用被接受了，是系统层面把震动压掉了 （静音/勿扰、系统里关了触感、省电模式），或者这台设备的马达做不出这么短的脉冲。
