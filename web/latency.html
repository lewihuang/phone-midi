④ Mode B 链路 — 姿态 → 投影 → CC（无滤波）

⑤ Mode B 无可调参数

旧版的 mincutoff / beta / gravityAvgMs 三个滑杆已删除：链路改成纯投影后， 任何滤波都会重新引入滞后，而加速度计污染根本不在滤波能处理的频段里（快速翻转时手部线加速度达 2–3 g）。 因此 Mode B 与 Mode A 现在是同一条架构，没有需要调的东西，也不会被调试页悄悄改掉主控手感。
