# 2026-09-27 CC 廊条（推子页底部的 Shortcut Pad 第 4 页）

需求与决策见 [spec/shortcut-pad.md §10](../spec/shortcut-pad.md)（D37–D41）；本页记录**实现**、**实测**与文档影响。

一句话：Digital Fader 的 **A/B 运行界面**底部多了一小块——**Shortcut Pad 第 4 页**那八格
（编号固定 **24–31**）。推子正跑着、手机就在手里，顺手按一下就能让 DAW 显示某条参数的 CC 廊；
"第 4 页 = CC 廊开关"是用户侧的约定，**映射在 DAW 里做**，手机与 Bridge 都不认识宏。

---

## 改动

### 手机端

| 文件 | 改动 |
|------|------|
| `web/padgrid.js` | **新增**：格子阵列的共用实现（这一版的重构落点）。管六件事：建格、绘制、按下与松开、离线拒按、震动确认、松手痕迹；对外 `createGrid(el, {page, isConnected, send, haptic, onBlocked, onSent})`、`triggerId()`、`haptic()` |
| `web/pad.js` | 改为调用共用实现，只剩"面板自己的事"：6 页、页签、布局下发、断线重连、wake lock（**273 → 175 行**；搬走的那一坨变成 `padgrid.js` 的 147 行，两处共用） |
| `web/pad.html` | 引 `padgrid.js`；`pad.js?v=29 → 30` |
| `web/fader.html` | 运行界面加 `#ccLane`（标题 + `#ccLaneGrid`）与紧凑 CSS；引 `padgrid.js?v=1`；`app.js?v=25 → 26` |
| `web/app.js` | 接 `pad_layout`（**只取第 4 页**）、`applyPadLayout()` / `updateCcLane()`、把连接状态同步到格子；`MODES.A/B` 加 `ccLane: true` |

**Bridge：零改动**（这一版前端不改协议）。推子页本来就是 `/ws` 的一个客户端，Bridge 一直在给它发
`pad_layout`（连接时一次、PC 端编辑后广播），以前只是被 `app.js` 忽略了。

### 关键实现点

- **不新增协议、不新增接口**：内容来自既有 `pad_layout`；按下仍是 `{kind:'trigger', id}`，
  与面板页走**同一条** Note 通路（ADR 0004），所以 DAW 侧的映射两边共用。
- **只画第 4 页**：`CC_LANE_PAGE = 3` 是一个**常量**（约定，不是配置）；布局里没有第 4 页就整块不显示。
- **只占 225px**：2 列 × 4 行与第 4 页同构，但行高写死 46px、不抢剩余空间（见下面"量出来的尺寸"）。
- **门槛**：`active && 第 4 页布局已到 && MODES[currentMode].ccLane`——即**只有 A/B 的运行界面**。
  C 要摇晃手机、按不了屏幕；设置界面不摆演奏用的东西。
- **边角状态**：布局未到 → 收起；未连接 → 变灰不可按 + 按下不发也不振；断连/返回 → 先松开按住的格子；
  空文字的格子**与面板完全一致**（没填就空白，用户选的这一档）。

## 实测

**手机端（`tests/pages_smoke.mjs`，本页新增 14 项，该套件 86 → 100 项）**：八格与面板同构、
**不铺满**（行高固定、无 `flex:1`、无 `grid-template-rows`）、布局未到收起、未连接按下零消息零震动、
布局到达后露面且标题/文字/颜色/`ink` 正确、**只画第 4 页**（第 1/2/3 页内容一格都不漏）、
按下发编号 **24**、第八格 **31**、按下震动 25ms、松开发配对的 `up`、**Mode C 不摆**而 Mode B 又出现。
另外两条守在重构上：`pad.js` 不再自己建格/绑按下（两边共用一份实现）；形状仍由 `padgrid.js` 的 `COLS/ROWS` 定义。

**Bridge（`tests/bridge_boot_check.py` 新增 1 项）**：真的起一次 Bridge，确认 `padgrid.js` **服务得出来**
（它 404 的话两处按钮会一起哑掉，而页面看起来还是正常的）。
顺带修掉这套件自己的一处老毛病：结尾的分母**写死成 8**，加了检查也照旧打印 `8/8`——等于"新检查跑了没有"
看不出来。改成自己数（`total`），现在会如实打印 `9/9`。

**全套 327 → 342 项**（9 个套件，`powershell -File tests\run.ps1` 全绿；exe 已重打包，
`exe_web_check.py` 的"打包快照是否新鲜"随之通过）。

## 真机待确认

- **八格现在是空的**：`%APPDATA%\phone-midi-bridge\pad.json` 的第 4 页八格文字与颜色都是默认值，
  所以在手机上它们就是八块白方块。要在 PC 端编辑器里给第 4 页填上文字（例如 `CC1…CC8`，
  或直接写参数名），并在 Nuendo 里把 **Note 60–67** 映射成"显示 XX 的 CC 廊"。
- **46px 高的格子**握着手机时按得准不准（这只是 `fader.html` 里的一个值）。
- 底部这一块**要不要标题**（现在显示第 4 页的页标题，如"cc廊"）；标题长了会省略号截断。
