# 2026-06-30 Milestone 1: 完整通路 + GUI + exe 交付

## 完成功能

### 手机端 Web
| 功能 | 说明 |
|------|------|
| Pitch 采集 | DeviceOrientation API 主传感器 |
| 加速度计 fallback | devicemotion 备选（华为/老旧浏览器） |
| 实时 CC 显示 | 服务端回传实际映射值，不本地估算 |
| 发送开关 | 暂停/恢复 MIDI，保持 WebSocket 连接 |
| 实时配置 | CC 号（数字输入 0-127）、Channel（下拉 1-16）、范围 in_min/in_max，change 事件即时同步 |

### PC Bridge
| 功能 | 说明 |
|------|------|
| MIDI 输出 | ctypes 直调 winmm.dll，零编译依赖 |
| 映射引擎 | EMA 平滑、死区、linear/reverse/log/exp 曲线、运行时 update_range/update_target |
| HTTPS | 自签证书（cryptography），cert 写入 %APPDATA% |
| WebSocket | aiohttp，JSON 协议，双向通信 |

### GUI（tkinter, Industrial 暗色主题）
| 功能 | 说明 |
|------|------|
| 设备选择 | 列表显示所有 MIDI 设备，预选 loopMIDI |
| 状态面板 | URL、设备名、客户端数、实时 CC 值、绿色呼吸指示灯 |
| 持久窗口 | START → 运行态 → STOP 返回，QUIT 退出 |
| 无 CLI 窗口 | PyInstaller --noconsole（runw.exe bootloader） |
| 品牌 | 标题"手机MIDI推子"，Powered by Levi黄，中文操作说明 |

### 打包
- `phone-midi-bridge.exe` — 单文件，~19MB，双击即用
- 内置 config + web 资源
- 命令行兼容：`--list-ports`, `--no-gui`, `--midi-name`
