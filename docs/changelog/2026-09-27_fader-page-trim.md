# 2026-09-27 推子页一轮界面精简（用户逐条提的四件事）

上一轮做的是**加**（底部第 4 页条，见 [2026-09-27_cc-lane-strip.md](2026-09-27_cc-lane-strip.md)）；
这一轮全是**减**：用户真机看完列了四条，都在 `/fader.html` 上。

一句话：选择 mode 那一屏去掉永远说"未连接"的状态行；运行界面去掉第二个返回键（只留左上角那个，
但它改回**上一层**）；当前值的大数字缩小一半；进度条下面那行"映射 CCx Chx"整行删掉。

## 四条改动

| # | 用户原话 | 做法 | 为什么这么做 |
|---|----------|------|--------------|
| 1 | 「在 Digital fader 选择 mode 的页面顶部的连接状态始终显示"未连接"，这一行直接删了」 | `#status` **从 body 顶部挪进 `.runtime-head`**（左：状态胶囊 / 右：运行中 · 模式名），设置界面里它属于收起来的运行面板，压根不渲染 | 那一行在设置界面永远只会说"未连接"——设置界面**根本没有 WebSocket**（推子页只在按了「启动」之后才连 Bridge），所以它不是"状态"，是句废话。但它**在运行界面说的是真话**（已连接 / 重连中… / 未连接），那条信息不能丢：推子断线时用户得看得见。挪位置一次解决两件事，不需要脚本去藏它（实测：设置界面里它的 `getBoundingClientRect()` 是 `[0,0,0,0]`） |
| 2 | 「启动推子以后的页面嵌套了两个返回键……只需要保留最顶部的"返回"键，但是应当返回上一层，即 mode 选择页面」 | 删掉 `.runtime-head` 里那个 `‹ 返回`；整页只剩 `.topbar` 里那一个 `#btnBack`。它仍是 `<a href="/">`，但 `app.js` 在**运行中**拦下点击改调 `returnToSetup()` | 两个返回键挨着、行为还不一样（上面回主页、下面回模式选择），是这次最刺眼的一处。用户要的语义其实就是"**返回上一层**"：设置界面的上一层是首页（所以保留 href 不动），运行界面的上一层是模式选择（所以运行中拦截）。设置界面不拦截 → 链接语义、长按新开标签都还在 |
| 3 | 「cc 值显示的数字字体过大，缩小一半」 | `.pitch-value` 由 **72px → 36px**（实测高度 104px → 52px） | 就是那个显示当前值的大数字（A/B 显示 CC 值、C 显示音分）。字号是页面专属覆盖，不动 `ios.css` 的 54px 默认值（校准页的 `.cc-big` 还在用它） |
| 4 | 「进度条下一行"映射 CCx Chx"这一行，删掉」 | 删掉整行 `.cc-row`：标记 + 页面 CSS（`.cc-row` / `.cc-tag` / `.cc-val`）三处一起清，`app.js` 里 `elCcTag` / `elCcVal` 的全部写入也一并删掉 | 它把同一件事说了两遍：CC 号与通道在下面配置行里就能改，值就是上面那个大数字。**必须三处一起删**——只删标记的话，`app.js` 里 `elCcVal.textContent = …` 会在每个传感器事件上抛错（`null.textContent`）。测试里专门守这一条 |

## 实测

**离线断言（`tests/pages_smoke.mjs`，本套件 100 → 107 项）**：

- 连接状态住进了运行面板（`id="status"` 出现在 `id="runtimePanel"` **之后**）；设置界面里它的矩形是 `[0,0,0,0]`。
- 整页**只有 1 个** `class="btn-back"`；设置界面点它不被拦截；**运行中**点它 → 拦截 + 运行面板收起、设置面板回来（真的驱动了一次点击，不是只读源码）。
- `.pitch-value` 是 `36px`。
- `ccTag` / `ccVal` / `cc-row` 在标记、CSS、`app.js` 里**都**不存在了；配置行（CC / Ch / 范围）与它的 `row-gap` 仍在。
- 大数字减半的那条是替换掉旧断言（旧断言守的是"映射行与 CC 行各自留了高度"——那行已经不存在了）。

**量出来的几何（无头 Edge + `getBoundingClientRect`，390×844）**：

| 元素 | 位置（top→bottom） |
|------|-------------------|
| 返回键（唯一） | 12 → 48 |
| 状态胶囊 / 模式名（同一行） | 54 → 81 / 60 → 74 |
| 大数字 | 97 → 149（原 72px 时是 104px 高，现已减半） |
| 进度条 | 167 → 179 |
| 配置行 | 207 → 281 |
| 发送按钮 | 329 → 379 |
| 第 4 页条（八格 177×46） | 391 → 616 |
| 作者行 | 642 → 659 |

页面内容约 **683px**（上一轮是 838px）——**在最矮 749px 的视口里也完全不滚动**，390×844 上底部还多出约 **160px** 空白。
底部那条（第 4 页条）**没有跟着放大**：用户要的是"顺手按得到"，不是"占满"；真嫌小就调 `fader.html` 里的
`grid-auto-rows` 一个数（现在 46px，放到 ~85px 都还塞得下）。
