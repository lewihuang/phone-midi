# 2026-06-30 Phase 1 MVP 代码

## 变更
- `bridge/server.py` — 新建。Python WebSocket 服务端。MappingEngine（EMA 平滑+曲线映射+死区）、MidiOutput（mido 封装）、aiohttp 路由（/ws /status /ports 静态文件服务）
- `bridge/requirements.txt` — 新建。mido + aiohttp + python-rtmidi
- `bridge/config/default.json` — 新建。默认映射配置（pitch→CC11 Ch1，线性曲线，EMA alpha 0.15）
- `web/index.html` — 新建。手机端界面（pitch 角度显示、CC 预览条、状态指示）
- `web/app.js` — 新建。DeviceOrientation API 采集、WebSocket 发送、iOS 权限处理、自动重连
- `README.md` — 覆盖。新项目说明

## 原因
Phase 1 Web MVP。手机浏览器采集 pitch → WebSocket JSON → Python Bridge → mido → DAW。

## 影响
- 浏览器需支持 DeviceOrientation API（手机 Chrome/Safari 均支持）
- iOS 13+ 需用户点击授权
- HTTPS 或 localhost 要求（Bridge 在局域网内提供 HTTP 页面）
